# Connection Verification Report

**Method.** Every connection was checked three ways:

1. **Hover check while wiring.** Before each wire was placed, the pointer was held over the source pin and the destination pin, and the pin name in Tinkercad's tooltip was read (for example "D13", "Trigger", "Anode", "Wiper").
2. **Live netlist check.** After each wire, the editor's internal netlist was read back to confirm which terminals were actually joined. A wire that only looked close to a pin did not pass.
3. **Exported-file check.** The `.brd` file generated by Tinkercad was parsed, and its signal list was compared line by line with the connection table.

Result: **22 / 22 supported connections VERIFIED, 0 INCORRECT, 0 MISSING. 4 sensor modules are NOT SUPPORTED BY TINKERCAD.**

## Safety checks

- **No short circuits.** 5V and GND are separate nets with no direct link. Each net list contains only the expected terminals.
- **No pin cross-connected to a neighbour.** Every signal net has exactly one Arduino pin.
- **Resistor values confirmed in the design data:** R2 = 220 Ω, R3 = 220 Ω, R4 = 10 kΩ.
- **LED polarity confirmed by hover tooltip:** each anode goes to its resistor, each cathode goes to GND.
- **Shared rails.** The HC-SR04 VCC and GND go to the servo's power and ground pins, and from there to the Uno. This is electrically the same 5V/GND net, as the BRD net list shows.
